# taqify

An [Agent Skill](https://agentskills.io) that makes AI-generated text sound like I (Taqi Jaffri) wrote it. See
[SKILL.md](SKILL.md) for the rules.

## Install

**Coding agents** (Claude Code, Codex, Cursor, Gemini CLI, and more) via
[npx skills](https://github.com/vercel-labs/skills):

```bash
npx skills add tjaffri/taqify-skill -g
```

**Claude** (chat or Cowork) and **ChatGPT**: download this repo as a zip (Code → Download ZIP),
then upload it in the app's Skills settings.

## Use

Ask your agent to "taqify" some text, or to write something as me.
